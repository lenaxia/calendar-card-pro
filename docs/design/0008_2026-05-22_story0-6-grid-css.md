## Decisions and rationale

1. **`color-mix` for today-column background tint**: gives a subtle 4%
   accent-color tint without needing a new CSS variable for the alpha. If
   the user's browser doesn't support `color-mix`, the rule simply has no
   effect (no fallback red error or layout glitch). Could swap to a CSS
   variable in a future release if support concerns arise.

2. **`.ccp-grid-day-header.today` styling**: today's column header gets the
   accent color and bold weight. Matches design doc §7 visual spec.

3. **`.ccp-grid-event-time` and `.ccp-grid-event-location`**: use the
   existing time/location font-size and color variables for consistency
   with the list view. Subtle opacity reduction (0.9) on the time
   sub-element to de-emphasize it relative to the title.

4. **`.ccp-grid-hidden-pill`**: empty selector body other than positioning
   primitives — actual content (`+N hidden`) is added by FR-2.6 in a later
   story (likely epic02 banner overflow). Story line 37 explicitly required
   this CSS even though the renderer doesn't yet emit the markup for it.

5. **`box-sizing: border-box` on `.ccp-grid-event`**: ensures the 2px
   accent border doesn't push width past 100% (which would cause overflow
   when laneCount=1 and width=100%).
