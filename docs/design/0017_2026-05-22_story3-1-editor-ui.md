## Summary

Added a `view` selector in the Core Settings expansion panel and a new "Time grid"
expansion panel that is revealed only when `view === 'time-grid'`. List-view-only
sections (`days_to_show`, Compact Mode, `show_empty_days`) are conditionally hidden
when grid view is active. A helper-text hint warns the user when
`time_grid_navigation_days < time_grid_max_days` (FR-7.6).

No changes to `src/rendering/render.ts` or `src/utils/events.ts` (Rule 5 honored).

### Concrete edits

1. **Import** — added `mdiViewWeek` to the existing `from '@mdi/js'` block (editor.ts:22-32).
2. **View selector** — added inside Core Settings near `time_range`, ahead of
   `days_to_show`. Uses `addSelectField` with string values `'list' | 'time-grid'`.
3. **`days_to_show` + helper-text** — wrapped in a `view !== 'time-grid'` conditional.
4. **Compact Mode section** — wrapped in a `view !== 'time-grid'` conditional
   (entire `<h3>` + helper-text + 3 fields + trailing helper-text).
5. **Event Visibility section** — partial wrap. `show_past_events` and
   `filter_duplicates` remain unconditional (apply to grid). Only `show_empty_days`
   is wrapped in the conditional.
6. **New Time-grid expansion panel** — rendered after the Core Settings panel,
   only when `view === 'time-grid'`. Contains all 11 grid fields plus 3 helper-text
   notes and the `_renderNavigationDaysHint()` warning.
7. **`_renderNavigationDaysHint` method** — added after `_handleStartDateModeChange`.
   Returns a `helper-text` div when navigation days < max days, otherwise `nothing`.
   Returns `TemplateResult | typeof nothing` (no `any`).

## Notes / Follow-ups

- **Translation strings** — all editor labels and helper-text in this story
  rely on translation keys (`view`, `view_list`, `view_time_grid`,
  `time_grid_settings`, `time_grid_*`, `time_grid_*_note`,
  `time_grid_navigation_days_warning`, etc.). These are intentionally **not
  added in this story** per story 3-1 line 121. Story 3-2 will populate them.
  Until then the editor will render fallback strings (the key itself, per
  `Localize.translate`'s 3rd-arg fallback in editor.ts:358).
- **`helper-text-warning` class** — the story permits reusing plain `helper-text`
  to avoid adding new CSS. We followed that path (`helper-text-warning` is not
  used).
- **MDI icon** — chose `mdiViewWeek` per the story's first suggestion. It pairs
  visually with the existing `mdiCalendarMonth` (Core Settings) icon.
- **`type` parameter on the navigation-days hint** — narrowed from
  `as number` to a typeof-guard (`typeof navDays === 'number' && typeof maxDays === 'number'`).
  This is defensive: until story 0-3 validation lands the values could be
  user-provided non-numerics, and a NaN comparison would silently never trigger
  the hint. Cost is one extra check.
