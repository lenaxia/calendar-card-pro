## Decisions and rationale

1. **`time_grid_allday_bg_opacity` label says "0–100"** (not "0–1" as the
   epic03/story3-2 spec sketch had). This aligns with the resolution
   from story 2-1 worklog (default 20, scale 0..100). The story 3-2
   spec sketch was authored before story 2-1 caught the convention
   conflict; ships with the corrected scale.

2. **`time_grid_show_now_line` label uses escaped `\"now\"`** to keep
   "now" inside double quotes inside a JSON string. JSON parser
   accepts this; the rendered editor label is `Show "now" line`.

3. **Top-level nav strings vs editor strings split**: nav strings
   (`time_grid_today` etc.) at top level matches the existing
   convention for user-facing UI strings (`noEvents`, `error`,
   `loading`). Editor labels under `editor.*` matches the pattern
   for form-field labels (e.g. `editor.first_day_of_week`).
