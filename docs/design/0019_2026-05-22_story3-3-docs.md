## Notable decisions

1. **Screenshot omitted**: story line 62 explicitly permits this. The
   `docs/images/` directory does not exist; the README does not include a
   `<img>` tag pointing to a non-existent file. A real screenshot can be
   added in a follow-up doc-only PR after the feature is merged and a
   sample HA dashboard is available.

2. **`time_grid_allday_bg_opacity` documented as 0–100 default 20**, not
   0–1 default 0.2 as the original story 3-3 spec sketch (line 76) said.
   The story spec was authored before story 2-1 caught the convention
   conflict; the code ships with 0..100 scale to match
   `event_background_opacity` and the existing `convertToRGBA` helper
   (which divides by 100 internally). README and RELEASE_NOTES reflect
   the shipped scale.

3. **RELEASE_NOTES placement**: added at the very top as a new
   `# Unreleased` H1, separated from existing `# Calendar Card Pro v3.2.0`
   by `---`. When the maintainer (alexpfau) cuts the next release, they
   can rename `# Unreleased` to e.g. `# Calendar Card Pro v3.3.0`.

4. **Architecture.md data-flow paragraph kept at the same level of detail
   as the existing "Event Data Flow"** — 5 numbered steps, then 3 short
   paragraphs about the lifecycle / interval / fetch decoupling. Avoids
   re-stating implementation details available in the design doc.
